# House Price Prediction – Baseline ML Project

This project explores a real-world housing dataset and builds a **baseline machine learning model** to predict house prices.

## What’s inside

- Exploratory Data Analysis (EDA)
- Feature selection & preprocessing
- Handling missing values
- One-Hot Encoding for categorical features
- Linear Regression model
- Model evaluation (MAE, R²)
- Feature importance visualization

## Why this project

The goal is not to build a perfect model, but to demonstrate:
- A complete ML workflow
- Clear reasoning from raw data → insights → model
- Learning progression and experimentation

## Files

- `01_eda_baseline_linear_regression.ipynb`  
  Baseline analysis and linear regression model.
